# MON BLOC NOTES

C'est une application qui affiche les notes dans un bloc-notes du pllus recent au plus ancien avec
comme information le nom puis la date de creation ou de modification.   
Lors de l'ajout d'une nouvelle note ou de la lecture d'une ancienne, il est possible de modifier les
valeurs inscrite avant l'enregistrement avec les boutons **Redo**, **Undo**,et **Enregistrer**
dans l'editeur. Il est aussi possible de voir les coordonnees GPS simple inscrite dans le champs
editText de la note a l'aide du bouton **GPS**.

## COMPILATION SIMPLE

Pour compiler mon projet il faut :
- Ouvrir le projet dans Android Studio
- Chosir un appareil comme emulateur
- Cliquer sur Run dans mon projet
- Pour voir les details d'une note ou la modifier appuyer sur la note en question
- Pour ajouter une nouvelle note , appuyer sur le bouton ajouter
